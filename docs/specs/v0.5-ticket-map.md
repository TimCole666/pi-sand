## #66 — host ingress/authority foundation

Own the persisted protected-session authority contract and the atomic durable Telegram ingress generation fence.

Do not implement pi-sand domain semantics beyond a test double/adapter needed to exercise the host seam.

## #67 — current-turn/workspace authority

Consume #65 evidence and the focused #71 review. Preserve official Codex mechanics.

Make the protected writer surface closed and verified, and require a **pinned process-containment profile** for Codex-native file/shell execution. Background-terminal inventory alone is not enough: the proof must cover descendant processes that attempt to detach/outlive T1.

Before T2 gains protected authority, prove that all T1 Codex descendants retaining authoritative-workspace write capability are gone/isolated and that every other allowed T1 writer capability is quiescent/isolated.

Uncontained profiles such as `danger-full-access` are incompatible unless an equivalent descendant-containment guarantee is independently proved.

Do not build a generic process-containment runtime or dynamic-tool mutation framework in pi-sand.

## #68 — GitHub protected effect

Reuse OpenClaw Gateway publisher/credential/reconciliation. Add current one-shot authority at actual mutation boundaries and prove credential isolation from Codex.

Treat publication-side local Git mutation/recovery state as a writer capability too: local ref/index/worktree mutation must be current-authority fenced or isolated before T2 authority opens.

Do not build pi-sand GitHub transport or a generic Effect subsystem.

## #69 — authoritative final dispatch

Gate the actual protected Telegram terminal dispatch under current generation/turn/revision authority.

Do not build ResultDelivery or a generic delivery runtime.

## #70 — minimal semantics + vertical proof

Only after host seams exist, implement:

```text
Obligation
current_revision
InputDecision
```

`effect_key` stays host/Gateway publication identity; do not add a pi-sand Effect record.

Drive the complete Telegram -> OpenClaw -> contained Codex execution -> GitHub -> Telegram journey with the required race/restart evidence.

## Stop rule

A ticket must stop and hand back a concrete failing invariant if it appears to require any of:

```text
AgentHarness replacement
Codex protocol reimplementation
new pi-sand supervisor/runtime
scheduler/worker pool/DAG
generic process-containment/filesystem/capability/effect/evidence framework
second transcript/context system
```

Do not rescue a tracer bullet by expanding pi-sand.
