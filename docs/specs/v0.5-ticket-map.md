## Stop rule

A ticket must stop and hand back a concrete failing invariant if it appears to require any of:

```text
AgentHarness replacement
Codex protocol reimplementation
new pi-sand supervisor/runtime
scheduler/worker pool/DAG
generic filesystem/capability/effect/evidence framework
second transcript/context system
```

Do not rescue a tracer bullet by expanding pi-sand.
